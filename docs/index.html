알아서 업데이트

설치형은 새 버전을 알아서 받아 두고, 프로그램을 끌 때 설치해요.

설치 방법

3분이면 끝나요.

  1. 내려받기

    위의 설치형 내려받기 버튼을 눌러 설치 파일을 받아요.

  2. 설치하기

    받은 파일을 실행해요. 관리자 권한 없이 내 계정에 설치돼요.

  3. 시간표 넣기

    오른쪽 아래 트레이의 시계 아이콘을 두 번 눌러 설정 창을 열고, 시정표와 시간표를 입력해요.

"Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러 주세요. 코드 서명 인증서가 없는 무료 프로그램이라 나오는 경고예요. 학교 보안 정책으로 실행이 막히면 정보 담당 선생님께 허용을 요청하세요.

설치형과 무설치판

잘 모르겠으면 설치형을 쓰세요.

설치형 (추천)무설치판
설치필요해요 (관리자 권한은 필요 없어요)필요 없어요. 원하는 폴더에 두고 실행
업데이트자동으로 받아서 설치새 버전이 나오면 알려 주고, 직접 다시 받아야 해요
바로가기시작 메뉴·바탕화면에 생겨요직접 만들어야 해요

자주 묻는 질문

 

모니터가 하나뿐이어도 쓸 수 있나요?

네. 설정 창의 화면 탭에서 학생 위젯과 교사 위젯을 같은 모니터에 둘 수 있어요.

업데이트하면 설정이 지워지나요?

아니요. 시정표, 시간표, 아침 할 일, 알림 설정은 그대로 남아요. 다른 PC로 옮길 때는 설정 창의 일반 탭에서 "설정 내보내기"를 쓰세요.

수업 중에 갑자기 업데이트로 다시 시작되나요?

아니요. 새 버전은 미리 받아 두기만 하고, 프로그램을 끄거나 PC를 끌 때 설치해요. 바로 설치하고 싶으면 트레이 메뉴의 "업데이트 설치 후 다시 시작"을 누르세요.

무설치판인데 새 버전은 어떻게 받나요?

새 버전이 나오면 알림이 떠요. 이 홈페이지에서 무설치판을 다시 받아 기존 파일을 바꿔 주세요. 설정은 그대로 남아요.
