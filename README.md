# 우리반 시계

교실 듀얼 모니터용 일정 안내 위젯입니다.

- **학생 모니터**: 현재 시각과 교시, 남은 시간, 오늘 시간표, 아침 할 일, 수업 시작 3분 전 배너·1분 전 전체 화면 알림
- **교사 모니터**: 구글 캘린더 일정, 구글 태스크 할 일, 아침 할 일 바로 편집, 알림 일시정지
- 인터넷이 끊겨도 시계·교시·알림·아침 할 일은 그대로 동작합니다.
- 교사 일정과 할 일은 교사 위젯에만 보이고 학생 화면에는 절대 나오지 않습니다.

## 설치

[홈페이지](https://seoseo1234.github.io/scheduler/)나 [GitHub 릴리스](https://github.com/seoseo1234/scheduler/releases/latest)에서 내려받으세요.

| 파일 | 설명 |
|---|---|
| `ClassroomClock-Setup.exe` | 설치형. 관리자 권한 없이 내 계정에 설치되고 시작 메뉴·바탕화면 바로가기가 생깁니다. 새 버전을 자동으로 받아 두었다가 프로그램을 끌 때 설치합니다. |
| `ClassroomClock-portable.exe` | 무설치형. 원하는 폴더에 두고 바로 실행합니다. 새 버전이 나오면 알려 주니 홈페이지에서 다시 받으세요. |

### 새 버전 내기

`package.json`의 `version`을 올리고 같은 이름의 태그(예: `v0.2.0`)를 올리면, GitHub Actions가 설치 파일을 만들어 릴리스에 올립니다. 설치된 프로그램은 이 릴리스를 보고 업데이트합니다.

> **"Windows의 PC 보호" 경고가 뜨면**: 코드 서명 인증서가 없는 프로그램이라 SmartScreen 경고가 나올 수 있습니다.
> **추가 정보 → 실행**을 누르면 설치됩니다. 학교 PC 보안 정책상 실행이 막히면 정보 담당 선생님께 허용을 요청하세요.

처음 실행하면 주 모니터가 아닌 모니터를 학생 모니터로, 주 모니터를 교사 모니터로 자동 지정합니다.
작업 표시줄 오른쪽 아래 트레이의 시계 아이콘을 **더블클릭**하면 설정 창이 열립니다.

## 처음 설정 순서

1. **화면** 탭: "모니터 확인"을 눌러 각 화면의 번호를 보고 학생/교사 모니터를 고릅니다.
2. **시정표** 탭: 기본 시정을 학교 시간에 맞게 고치고 저장합니다. 단축 수업 같은 시정은 "복사해서 만들기"로 추가하고 요일이나 날짜에 지정합니다.
3. **시간표** 탭: 요일×교시 칸에 과목을 입력하고, 과목별 준비물(예: 체육 → "체육복 입고 운동장으로 가요.")을 적습니다.
4. **아침 할 일** 탭: 매일 하는 일과 요일별 할 일을 적습니다. 그날만 하는 일은 교사 위젯에서 바로 추가할 수 있습니다.
5. **알림** 탭: 알림 시점·문구·소리를 확인하고 "알림 미리보기"로 학생 화면에서 확인합니다.
6. **구글 연동** 탭: 화면의 안내 5단계를 따라 연결합니다. (아래 참고)
7. 위젯을 원하는 자리로 끌어 놓고 크기를 맞춘 뒤, 트레이 메뉴 → **위젯 위치 잠금**을 켭니다.

## 위젯 다루기

- 잠금을 풀면 위젯 아무 곳이나 끌어서 옮기고, 가장자리를 끌어 크기를 바꿀 수 있습니다. 위치는 모니터별로 저장됩니다.
- **표시 레이어**
  - 항상 위: 다른 창 위에 항상 보입니다. (학생 위젯 기본값)
  - 바탕화면 고정: 다른 창 아래, 바탕화면 위에 있습니다. **위치를 잠그면** 바탕화면에 붙어 "바탕화면 보기(Win+D)"에도 사라지지 않습니다. (교사 위젯 기본값)
  - 항상 아래(호환 모드): 바탕화면 고정이 이상하게 보이는 PC에서 쓰세요.
- 교사 위젯 **가리기**: 위젯의 "가리기" 버튼 또는 단축키(기본 `Ctrl+Alt+H`, 설정 → 일반에서 변경)
- 시험·행사 때: 교사 위젯이나 트레이 메뉴에서 "오늘 알림 끄기"(다음 날 자동으로 다시 켜짐), "1시간 알림 끄기"
- 교사 모니터를 분리하면 교사 위젯은 학생 화면으로 옮겨지지 않고 숨겨집니다.

## 구글 캘린더·태스크 연동

구글 클라우드 콘솔 설정 없이, 교사 계정에 작은 Apps Script 웹 앱을 만들어 연결합니다. 코드는 [`apps-script/Code.gs`](apps-script/Code.gs)에 있고, 설정 화면의 "Apps Script 코드 복사" 버튼으로도 복사할 수 있습니다.

1. [script.google.com](https://script.google.com)에서 새 프로젝트를 만듭니다.
2. 편집기 내용을 지우고 코드를 붙여넣은 뒤 저장합니다.
3. 왼쪽 **서비스 +** → **Google Tasks API**를 추가합니다.
4. 설정 화면에서 **무작위 생성 → 복사 → 토큰 저장**을 누르고, Apps Script **프로젝트 설정 → 스크립트 속성**에 이름 `TOKEN`, 값으로 붙여넣습니다.
   - (선택) `CALENDAR_IDS`: 보여줄 캘린더 ID를 쉼표로 구분해 적습니다. 비우면 숨기지 않은 모든 캘린더를 보여줍니다.
5. **배포 → 새 배포 → 웹 앱**, 실행 사용자 **나**, 액세스 권한 **모든 사용자**로 배포하고 권한을 허용합니다. 나온 URL(`…/exec`)을 붙여넣고 **연결 테스트** → **저장**.

토큰은 Windows 보안 저장소(DPAPI)로 암호화해 이 PC에만 저장하며, 설정 내보내기 파일에도 들어가지 않습니다.

**연결이 안 될 때**

| 메시지 | 확인할 것 |
|---|---|
| script.google.com에 접속하지 못했어요 | 인터넷 연결, 학교망 방화벽(script.google.com 허용 필요) |
| 토큰이 일치하지 않아요 | 스크립트 속성 `TOKEN` 값과 저장한 토큰이 같은지 |
| 웹 앱에 접근할 수 없어요 | 액세스 권한 "모든 사용자", URL이 `/exec`로 끝나는지. 코드를 고쳤다면 "배포 관리"에서 새 버전으로 다시 배포 |
| Apps Script 실행 중 오류 | 서비스에 Tasks API를 추가했는지 |

오프라인이거나 동기화에 실패하면 교사 위젯은 마지막으로 받은 내용을 "오프라인 · 9:12 기준"처럼 표시합니다.

## 백업과 다른 PC로 옮기기

설정 → **일반** → 설정 내보내기/가져오기. 시정표·시간표·아침 할 일·알림·구글 표시 설정이 JSON 파일로 저장됩니다.
화면 배치(모니터·위치)와 구글 토큰은 PC마다 다르므로 파일에 넣지 않습니다.

설정 파일 위치: `%APPDATA%\우리반 시계\` (`settings.json`, 토큰은 `secrets.json`에 암호화, 구글 캐시는 `google-cache.json`)

## 개발

Node.js 22 이상이 필요합니다.

```bash
npm install
npm run dev        # 개발 모드 실행
npm test           # 단위 테스트 (시정표 엔진, 알림 스케줄러, 구글 데이터 처리)
npm run typecheck  # 타입 검사
npm run dist       # 설치 파일(NSIS) + 무설치 exe 빌드 → dist/
```

> PowerShell에서 `npm`이 "스크립트를 실행할 수 없으므로…" 오류로 막히면 `npm.cmd run dev`처럼 `npm.cmd`를 쓰세요.

### 구조

```
apps-script/Code.gs        구글 Apps Script 웹 앱 (교사 계정에 배포)
src/shared/schedule/       시정표 엔진 (순수 함수 + 테스트): 날짜→시정, 현재/다음 구간, 알림 계산·스케줄러
src/shared/google.ts       구글 응답 검사, 일정·할 일 표시 계산 (+ 테스트)
src/main/                  Electron 메인: 창·모니터 관리, 알림 서비스, 구글 동기화, 트레이, 바탕화면 고정
src/preload/               창별 preload (학생/교사/설정/알림 오버레이가 각자 필요한 채널만 노출)
src/renderer/              React 화면: student, teacher, settings, overlay, identify
scripts/make-icons.cjs     아이콘 PNG 생성
```

**개인정보 분리**: 학생 위젯과 알림 오버레이는 별도 preload를 써서 교사용 IPC 채널에 접근할 수 없고, 메인 프로세스는 구글 데이터를 교사 위젯 창으로만 보냅니다. IPC 요청은 보낸 창이 맞는지 확인한 뒤 처리합니다.
